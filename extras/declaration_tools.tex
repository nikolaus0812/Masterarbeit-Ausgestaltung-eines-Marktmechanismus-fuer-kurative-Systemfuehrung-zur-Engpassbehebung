Ich erkläre, dass ich das KI-System Claude (Anthropic) in den Modellversionen Claude Opus 5, Claude Opus 5.5 und Claude Fable 5.1 in der Entwicklungsumgebung Claude Code als Hilfsmittel für die folgenden Zwecke verwendet habe:
\begin{itemize}
	\item Recherche in den verwendeten Quellen und Prüfung von Belegstellen.
	\item Sprachliche Überarbeitung, Grammatikkorrektur und Verbesserung der Lesbarkeit sowie Formulierung von Textabschnitten nach meinen inhaltlichen Vorgaben.
	\item Prüfung der Arbeit auf Konsistenz von Begriffen, Zahlen und Verweisen.
	\item Refaktorisierung von Python-Code für Modellläufe, Auswertungen und Abbildungen.
\end{itemize}
Alle Ausgaben wurden von mir geprüft und validiert. Die inhaltlichen Entscheidungen, der Entwurf des Marktmechanismus, das Optimierungsmodell und die Auswertung der Ergebnisse stammen von mir.
